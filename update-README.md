## Project Overview
This is a personal manual testing project on the **OpenCart demo website**: [https://demo.opencart.com](https://demo.opencart.com)

Purpose:
- Design and execute manual test cases for core features (Authentication, Cart, Checkout)
- Document test plan, execution reports, and bug reports
- Practice professional GitHub workflow: branch → PR → merge → main

## Repo Structure
/test-plan         → Contains overall test plan
/test-cases        → Individual test cases (Markdown or Excel)
/test-execution    → Execution logs and results
/screenshots       → Screenshots/evidence of test execution
README.md          → Project description
